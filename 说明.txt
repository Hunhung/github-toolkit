================================================
                电脑工具   说明
================================================

打开这个文件夹，看到的就都是工具。
不知道点哪个，就双击「1_不知道怎么选_点这个」。

------------------------------------------------
四个按钮，分别管什么
------------------------------------------------

【2_GitHub打不开_点这个】
    什么时候点：打开 github.com 打不开、白屏、
                跳到一个写着 nginx 的怪页面。
    它会做：清缓存 -> 查代理 -> 测两条线路
            -> 直接告诉你哪条坏了。

【3_贡献数不涨_点这个】
    什么时候点：GitHub 上提交没有头像、
                贡献日历不涨。
    它会做：扫描本机所有仓库，看提交邮箱
            有没有写错。邮箱错了 GitHub 就不算贡献。

【4_git推送失败_点这个】
    什么时候点：推代码时报 Connection was reset，
                或者一直卡住不动。
    它会做：把 git 接到代理上，实测一次告诉你成没成。

【5_网络或代理出问题_点这个】
    什么时候点：上不了外网、SakuraCat 好像没开、
                ChatGPT 打不开。
    它会做：查代理端口 -> 需要时自动把代理拉起来
            -> 测能不能上外网 -> 顺便看磁盘和配置。
    注意：会弹一个窗口，别关，等十几秒。
