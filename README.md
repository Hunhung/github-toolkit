# 电脑工具 · 桌面排障按钮

这台 Windows 机器上出过的坑，以及对应的「点一下就好」的按钮。
按**症状**组织，不按技术分类——遇到什么情况，点对应那个。

## 什么时候用

| 症状 | 点哪个 | 它会做什么 |
|---|---|---|
| 打开 github.com 打不开 / 白屏 / 跳到 nginx 页面 | `2_GitHub打不开_点这个.cmd` | 清 DNS 缓存 → 查代理 → 用 `curl --resolve` 验证 IP 是不是真 GitHub → 直连和代理两条线路各测一次 → 告诉你哪条坏了 |
| GitHub 上提交没有头像、贡献日历不涨 | `3_贡献数不涨_点这个.cmd` | 扫描本机所有仓库，逐个核对提交邮箱是不是 `77909766+Hunhung@users.noreply.github.com` |
| 推代码报 `Connection was reset` 或一直卡住 | `4_git推送失败_点这个.cmd` | 把 git 接到本机代理上，实测一次告诉你成没成 |
| 上不了外网 / SakuraCat 好像没开 / ChatGPT 打不开 | `5_网络或代理出问题_点这个.lnk` | 查代理端口 → 需要时把代理拉起来 → 测外网 → 顺便看磁盘和配置 |
| 不知道点哪个 | `1_不知道怎么选_点这个.cmd` | 一个菜单，按症状选 |

## 文档

- `说明.txt` — 给不看代码的人看的四句话版
- `详细手册.md` — 出过的所有问题 + 根因 + 修复步骤，当字典查
- `给AI的约束_复制用.txt` — 复制给 ChatGPT / 豆包 / WorkBuddy，让它们别再写错提交邮箱

## 两个坑（都真实踩过）

1. **提交邮箱写错 = 活干了但不算工分。** 正确地址只有这一个：
   `77909766+Hunhung@users.noreply.github.com`
   错的常见写法是 `77909766+user.noreply@github.noreply.com`——域名和用户名都变了。
   注意：全局配置对 ≠ 每个仓库都对，某个 AI 工具可能在它自己的工作目录里改过本地配置。
2. **本机直连 GitHub 会 `Recv failure: Connection was reset`**，git 必须走 `127.0.0.1:12450`。
   已写入全局配置；关代理时记得 unset，否则 git 也会跟着连不上。

## 约定

- `.cmd` / `.bat` 一律 **GBK + CRLF**（cmd 在中文系统按 GBK 解析），文件开头加 `chcp 936 >nul`
- 按钮命名 = **症状 + `_点这个`**，不要用「一键修复」「工具包」这类看不出用途的名字
- 路径里不写非 ASCII（用 `%USERPROFILE%` / `%APPDATA%` 代替 `C:\Users\你的用户名\...`）
